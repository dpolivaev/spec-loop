# Task ideas

1. Setup Gradle Java project configuration based on Kotlin Gradle variant.
2. Define Wordle game domain model (Word, Guess, Feedback, Rules).
3. Implement word list loader and validation (length, dictionary, allowed characters).
4. Implement guess evaluation (correct, present, absent) with duplicate letter rules.
5. Build game engine (state, attempt limits, win/lose conditions).
6. Add CLI to play a game (input loop, output formatting).
7. Add minimal UI to play a game.
8. Add persistence or replay support (optional).
9. Document build/run instructions and usage examples.
