# Diagrams and PlantUML

Design refinement often benefits from visual representations.

This framework encourages the use of PlantUML diagrams to reason about structure and verify assumptions. Diagrams are a tool for thinking and validation, not decoration.

## Rendering limitations on GitHub

GitHub does not render PlantUML natively.

## Alternatives

Diagrams can still be used effectively by:

- rendering in GitLab,
- viewing via IDE plugins,
- or including pre-rendered images.

## Recommended storage practices

Prefer committing `.puml` sources to keep diagrams reviewable and editable. If you also commit rendered images, keep them next to the source files so reviewers can easily correlate the two.
