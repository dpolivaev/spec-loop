# Write readable tests

Follow approved scope and project rules. This skill does not grant
editing permission or change workflow routes, phases, or approvals.

## Required guidance

Read each applicable reference fully:

- [test-design-and-writing.md](test-design-and-writing.md): when
  planning test coverage or designing, naming, identifying, writing,
  changing, or reviewing automated tests. It defines coverage, case
  purposes, names and identities, and readable test bodies. It works
  with or without Spec Loop.
- [spec-loop-task-verification.md](spec-loop-task-verification.md):
  when drafting, revising, or reconstructing a Spec Loop
  `Test specification`. It defines only task-recording and readiness
  rules. Do not load it for standalone test work.

Return to the invoking workflow afterward. Its scope, phase, approval,
and completion rules still apply.
